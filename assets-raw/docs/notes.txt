IMPLEMENTATION NOTES
- NASA Trek uses a separate WMTS GetCapabilities URL for each layer. Use the
  layer-specific URLs above to inspect the advertised tile matrix, style,
  image format, and projection before wiring a client.
- For NASA Trek, the URLs above are the WMTS capabilities endpoints, not a
  single XYZ tile URL. A WMTS client should read capabilities to obtain the
  correct style, TileMatrixSet, zoom levels, and image extension.
- For GIBS, the capabilities URL is shared by the service catalog; the
  individual visualization is selected by its Layer ID in the tile request.
- GIBS time-varying layers need a supported TIME value (YYYY-MM-DD). Static
  Blue Marble layers may not use a changing date. Read each layer's dimensions
  from the capabilities document rather than hard-coding assumptions.
- No API key is required for the public NASA Trek and GIBS services listed.
- All listed NASA Trek capabilities URLs returned HTTP 200 in the check.
- Earth identifiers were matched against NASA's official GIBS WMTS
  capabilities document. The catalog is the authority for current formats,
  dates, and tile matrix sets.
