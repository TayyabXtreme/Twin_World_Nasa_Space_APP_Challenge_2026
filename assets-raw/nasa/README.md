# NASA Space Apps 2026 challenge resources

Challenge: **Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars**
(resources tab: https://www.spaceappschallenge.org/2026/challenges/permanent-moon-base-locations-and-mars/?tab=resources)

Everything here was downloaded by the scripts in `scripts/` and can be re-downloaded or resumed at any time:

```bash
bash scripts/fetch-nasa.sh            # Moon + Mars planetary data (PDS Geosciences), ~1.3 GB, resumable
python scripts/fetch-earth.py         # NASA Worldview snapshots + Earthdata metadata for every Earth analogue
python scripts/fetch-partners.py --full   # CSA, Copernicus (ESA), ESA Open Science Catalog, JAXA
python scripts/preview-nasa.py        # render previews and sample every dataset at our sites
```

Raw files stay here (this folder is not served). Web-ready versions are built from them into `public/`.

## What is in each folder

| Folder | Dataset | Agency / archive | What it measures | Size |
|---|---|---|---|---|
| `moon/diviner/polar-resource/` | Diviner Polar Resource Product, south (`dlre_prp_south`) | NASA LRO · PDS Geosciences | Annual max and average temperature and **ice stability depth** for 2.88 M surface triangles around the south pole | 605 MB |
| `moon/diviner/global-maps/` | Diviner GDR L3 rock abundance (`dgdr_ra_avg`) and rock-free regolith temperature (`dgdr_st_avg`), 32 px/deg | NASA LRO · PDS Geosciences | Surface rock cover (landing hazard) and night-time regolith temperature | 2 × 88 MB |
| `moon/lola-south-pole/` | LOLA polar DEM and slope, 75°S–90°S, 240 m (`ldem_75s_240m`, `ldsm_75s_240m`) | NASA LRO · PDS Geosciences | Elevation and slope around every Artemis III candidate region | 2 × 29 MB |
| `moon/minirf/` | Mini-RF global CPR mosaic, 32 px/deg | NASA LRO · PDS Geosciences | Radar circular polarisation ratio (roughness and possible ice) | 265 MB |
| `mars/odyssey-grs/` | GRS element maps (H₂O, Fe, Cl, Si, K, Th) 5°, neutron epithermal flux 0.5°, hydrogen peaks | NASA Mars Odyssey · PDS Geosciences | Near-surface water-equivalent hydrogen and chemistry | 8 MB |
| `mars/mgs-tes/` | TES thermal inertia global map, 20 px/deg (day and night, 2007) | NASA MGS · PDS Geosciences | Thermal inertia (dust vs sand vs rock vs ice-cemented ground) | 70 MB zip |
| `earth/worldview/<site>/` | Worldview snapshots: MODIS true colour (clearest of several days), LST day and night (8-day), NDVI (16-day), ASTER GDEM relief | NASA Worldview / GIBS | Visual and thermal comparison of each Earth analogue | 8 MB |
| `earth/earthdata/` | CMR collection and granule listings (MOD11A2, MYD11A2, MOD13A2, ASTGTM, SPL3SMP_E, HLSL30) | NASA Earthdata | Exactly which files an ML pipeline needs per site (downloads need a free Earthdata Login) | small |
| `partners/csa/` | RADARSAT-1 and RCM dataset records, three RCM sample scenes (previews, metadata, one full-resolution HH band), CSA tutorial repos | Canadian Space Agency | Synthetic aperture radar over polar terrain | ~170 MB |
| `partners/copernicus/` | Best low-cloud Sentinel-2 L2A and latest Sentinel-1 GRD scene per analogue, with quicklooks | ESA Copernicus Data Space | Optical and radar scenes for each Earth analogue (full products need a free account) | small |
| `partners/esa-open-science-catalog/` | Products matching analogue themes | ESA Open Science Catalog | Pointers to permafrost, desert, ice, volcano datasets | small |
| `partners/jaxa/` | JAXA Earth API (public STAC) collection list | JAXA | Pointers to DEM, LST, precipitation, snow products | small |
| `_previews/` | PNG previews generated by `preview-nasa.py` | | Quick look at every dataset | |
| `site-samples.json` | Each dataset sampled at the app's Moon and Mars sites | | The numbers the website can show | |

## Needs an account (free) — not downloaded

| Resource | Why | How |
|---|---|---|
| NASA Earthdata granules (MODIS LST/NDVI HDF, ASTER GDEM tiles, SMAP) | Raw values for ML training | Earthdata Login, then the URLs in `earth/earthdata/granules-by-site.json` |
| Copernicus full products (Sentinel-1/2 SAFE) | Full-resolution optical and radar | Copernicus Data Space account; links in `partners/copernicus/scenes-by-site.json` |
| RADARSAT-1 scenes over specific sites | SAR of analogue sites (archive is on AWS `s3://radarsat-r1-l1-cog`, organised by date only) | Find scene IDs in EODMS (https://www.eodms-sgdot.nrcan-rncan.gc.ca), then fetch from AWS |
| JAXA G-Portal products | GCOM-C LST, ALOS-2 PALSAR SAR | G-Portal account (https://gportal.jaxa.jp) |
